# BOOTH発送照合

BOOTHの自家発送で、注文と発送コードの取り違えを防ぐための小さな道具です。

宛名印刷用CSVを読み込むと、注文ごとの照合リストになります。発送コードを注文に紐づけて記録でき、同じコードが2つの注文に使われると警告が出ます。

梱包票と外貼り票も印刷できます。

- 梱包票：注文ごとに、商品の封入チェック欄と発送コードの記入欄がついた票
- 外貼り票：封をした荷物の外側に貼る、注文番号と発送コードの小さい票

## 使い方の注意

- 導入は不要です。ページを開いてそのまま使えます。
- データはブラウザの中だけで処理し、外部に送信しません。外部スクリプトやアクセス解析も入っていません。
- 配送ラベル（宛名ラベル）は印刷できません。お使いの配送サービスで作ってください。
